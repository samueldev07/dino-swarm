DINO SWARM SURVIVORS Brief 03 Review

Khảo sát chuyển động & Tiến hóa trang bị Người Tiền Sử "Grok" (3 Tiers)
Chọn Gear Tier:
Hành động:
Xem lớn (Full Canvas 768×768 scale ~420px) — Nền đất xanh #7da05a Idle (Thở nhẹ)
Kích thước thật trong game (~90 px)
Đánh giá khả năng đọc nhanh trên Poki điện thoại

Đặc điểm chuyển động Phương án A:

  • Idle: Thở nhẹ (squash/stretch 2.0s), cơ bắp co giãn 2%.
  • Run: Hoán đổi frame nhịp 7 Hz, nhún nhảy (bob 5px) và hơi chúi về phía trước.
  • Attack: Frame vung đòn 0.15s kèm vệt chém cam rực rỡ (glowing slash arc).
  • Chân không nhảy: Mọi frame khóa chung baseline y=640, bàn chân đứng vững trên mặt cỏ.
Chọn Bộ trang bị lắp ghép:
Ghép tầng động: Thân mình + Vũ khí xoay quanh Hand Anchor theo thời gian thực Modular Rotated Sprite
Cỡ thật game (~90 px)
Vũ khí xoay theo góc quái vật

Đặc điểm Phương án B (Layered):

  • Thân mình giữ nguyên, vũ khí là file PNG riêng (512×512) xoay quanh điểm chốt cổ tay (Hand Anchor).
  • Góc vung chém: Lấy đà -60°, chém chớp nhoáng tới +100°, rồi thả chậm về thế thủ +25°.
  • Ưu điểm: Dễ dàng đổi bất kỳ vũ khí nào mà không cần vẽ lại thân mình.
  • Nhược điểm: Cổ tay và chuôi kiếm thiếu tính uốn lượn hữu cơ so với vẽ tay nguyên frame.
Khoảnh khắc Tiến hóa (1.3 giây):
Bậc hiện tại: Tier 1: Wild
Hiệu ứng Tiến hóa: Chớp sáng ➔ Scale Pop (1.0 ➔ 1.18 ➔ 1.0) ➔ Đổi Gear ➔ Bụi sao lấp lánh Sẵn sàng

Quy trình Diễn hoạt Tiến hóa 1.3s:

  1. 0.0s – 0.2s: Tích tụ năng lượng, chớp sáng trắng quanh thân.
  2. 0.2s – 0.5s: Phóng to giật nảy (Scale 1.0 ➔ 1.18), hoán đổi tức thì sang Gear bậc cao hơn.
  3. 0.5s – 1.0s: Tung tóe hạt tia lửa & bụi vàng (golden sparkles), cơ thể nảy nhẹ về 1.0.
  4. 1.0s – 1.3s: Vung kiếm uy phong ăn mừng rồi quay về trạng thái sẵn sàng chiến đấu.

Trải nghiệm cực kỳ thỏa mãn (satisfying), tạo động lực cày cuốc sinh tồn mạnh mẽ trên Poki.

Bảng kiểm tra Độ rõ nét trên màn hình Điện thoại (Cỡ thật ~90px tall cạnh nhau):
Tier 1: Wild (Chùy gỗ)
Ngực trần, khố da báo, chùy thô sơ. Silhouette gọn gàng, mắt to biểu cảm rất rõ.
Tier 2: Hunter (Kiếm xương)
Giáp sườn trắng tương phản với da rám nắng, kiếm xương răng cưa vươn dài nhận diện tức thì.
Tier 3: Warlord (Kiếm lửa + Mũ T-Rex)
Mũ sọ trắng sáng trên đầu, kiếm lửa vàng cam bừng sáng, khiên mai rùa gai bọc sườn rất đầm.

Tốc độ: 10 FPS
Sprite Animation Frame-by-Frame (Chân gập gối, tiếp đất, vung đòn thực thụ) Frame 1 / 6
Filmstrip Từng Frame Vẽ Tay

Đặc điểm Sprite Animation Thực Thụ:

  • Không phải Tween/Cắt xoay: Mỗi frame là một bức tranh vẽ riêng biệt, thể hiện rõ khớp gối co gập, bàn chân nhấc khỏi mặt đất, sải chân thể thao và hai tay vung chùy đổi nhịp.
  • Baseline khóa cố định: Bàn chân tiếp đất luôn chạm đúng baseline y=638, chuyển động nhịp nhàng không trượt chỗ.
Báo cáo Đánh giá của Art Producer: Cả 9 frame nhân vật đã được căn chuẩn tuyệt đối theo đường chân tiếp đất baseline y=640 (không bị nhảy chân khi hoán đổi dáng). Giữa Phương án A (Full Poses) và Phương án B (Layered Weapon): Phương án A cho nét cọ và dáng chém hữu cơ, gân guốc hơn hẳn; trong khi Phương án B cực kỳ tối ưu nếu muốn có hàng chục loại vũ khí thay đổi linh hoạt trong gameplay.
function renderTrueSpriteCanvas(cvId, w, h, dt) { const cv = document.getElementById(cvId); if (!cv) return; const ctx = cv.getContext('2d'); ctx.clearRect(0, 0, w, h); if (tsPlaying) { tsTimer += dt; const interval = 1.0 / tsFps; if (tsTimer >= interval) { tsTimer -= interval; const maxF = (tsMode === 'run') ? 6 : (tsMode === 'attack' ? 4 : 11); tsCurIndex = (tsCurIndex + 1) % maxF; renderTsFilmstrip(); } } let curImg = null; if (tsMode === 'run') { curImg = tsRunImgs[tsCurIndex % tsRunImgs.length]; } else if (tsMode === 'attack') { curImg = tsAttackImgs[tsCurIndex % tsAttackImgs.length]; } else { // Combo: 0..5 = run, 6 = idle, 7..10 = attack if (tsCurIndex < 6) curImg = tsRunImgs[tsCurIndex]; else if (tsCurIndex === 6) curImg = imgs.t1_idle; else curImg = tsAttackImgs[tsCurIndex - 7]; } if (!curImg || !curImg.complete) return; ctx.save(); ctx.translate(w / 2, h * 0.88); // baseline anchor ctx.scale(0.55, 0.55); ctx.drawImage(curImg, -384, -638); ctx.restore(); }
